# 历史上的今天

一个 Android 应用，展示今天历史上发生的大事。

## 特性
- 查看今日历史事件
- 任意日期浏览
- 收藏功能
- 实时联网获取维基百科数据
- 离线缓存兜底数据

## 技术栈
- Kotlin + Jetpack Compose
- MinSdk 24, TargetSdk 34
- Gradle 8.2.1 + AGP 8.2.1
- Wikimedia API 数据源

## 构建
```bash
./gradlew assembleDebug
```

## 安装
下载 `app-debug.apk` 即可安装到 Android 设备。
